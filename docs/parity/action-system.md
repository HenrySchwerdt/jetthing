# Action system and menus parity

Menus, context menus and toolbars built from the reference action groups
(`docs/spec/data/actions.json`, rendered in `docs/spec/menus.md`; Apache-2.0 derived facts,
see `docs/spec/data/NOTICE.md`) by the `jetthing-menu` crate. Statuses are conservative;
nothing here is `Verified`.
